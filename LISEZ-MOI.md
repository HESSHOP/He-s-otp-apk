# HES OTP : APK

L'appli ouvre https://he-s-otp.onrender.com/ (rien à reconstruire quand tu modifies le site).

1. Crée un dépôt GitHub et envoie tout ce dossier (y compris `.github`).
2. Onglet **Actions** > **Build APK** > **Run workflow**.
3. Une fois fini (~5 min), télécharge `HESOTP.apk` dans **Releases** ou dans les artefacts.

Liens web : ils s'ouvrent dans l'appli (croix pour fermer). WhatsApp : ouvre directement l'appli (choix WhatsApp / Business). Telegram : ouvre l'appli Telegram.
Page « Problème de connexion » hors ligne avec retour automatique, téléchargements, confirmation en quittant.
